# Pasta de Arquivos Estáticos

Coloque aqui os arquivos estáticos do sistema, como imagens, CSS e JavaScript.

## Logo do Sistema

Para usar a imagem do logo, coloque o arquivo com o nome `logo.png` nesta pasta (`public/logo.png`).

O sistema irá carregar automaticamente a imagem do logo nas páginas de login.

Se a imagem não for encontrada, o sistema usará um fallback SVG.
