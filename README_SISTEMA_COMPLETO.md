## 🚀 COMO USAR

### 1. Instalar Dependências
```bash
npm install
```
✅ PDFKit já instalado!

### 2. Configurar .env
```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=sua_senha
DB_DATABASE=condominio_db
JWT_SECRET=sua_chave_secreta
PORT=3000
```

### 3. Iniciar Servidor
```bash
npm start
```

### 4. Acessar
- URL: `http://localhost:3000`
- Login com usuário do sistema
